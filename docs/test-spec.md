## 2. テスト方針

本テストでは、以下の観点を確認する。

1. 正常な入力値でシミュレーションが実行できること
2. 不正な入力値に対してエラーメッセージが表示されること
3. 資産が0円以下になった場合に破綻年が表示されること
4. 年次テーブルと簡易グラフが表示されること
5. オフライン環境でも動作すること
6. 乱数を含まない条件では、手計算と結果が一致すること

乱数を使う機能は実行ごとに結果が変わるため、計算ロジック確認では、ショック確率を0%または100%に固定して確認する。

## 11. 合格基準

以下を満たせば、MVPとして合格とする。

- 初期値でシミュレーションを実行できる
- 成功率、破綻率、平均最終資産が表示される
- 資産が0円以下になった場合、破綻年が表示される
- 年次テーブルが表示される
- 簡易グラフが表示される
- 不正入力時にエラーメッセージが表示される
- ローカルファイルとして開いても動作する
- GitHub Pages上でも動作する
- 破綻後に余計な年の計算を続けない
- 手計算できる条件では、計算結果が期待値と一致する
