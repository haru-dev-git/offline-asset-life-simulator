# offline-asset-life-simulator
# オフライン資産寿命シミュレーター

## 概要

卒業論文で扱っている「4%ルール」「インフレ」「株価下落」「モンテカルロ法」を、ブラウザ上で可視化するために作成した学習用Webアプリです。

初期資産、初年度生活費、運用年数、通常時リターン、インフレ率、株価ショック確率などを入力すると、資産が何年持つか、30年後に資産が残る確率はどの程度かを確認できます。

## デモURL

https://haru-dev-git.github.io/offline-asset-life-simulator/

## 使用技術

- HTML
- CSS
- JavaScript
- Canvas

## 主な機能

- 初期資産・生活費・運用年数の入力
- 通常時リターン、通常時インフレ率の設定
- 株価ショック発生確率の設定
- インフレショック発生確率の設定
- インフレショック継続確率の設定
- モンテカルロ法による複数回シミュレーション
- 成功率・破綻率・平均最終資産の表示
- 破綻年の表示
- 年次テーブルの表示
- Canvasによる簡易グラフ表示
- 入力値チェックとエラーメッセージ表示

## 開発背景

卒業論文では、退職後の資産取り崩し戦略である4%ルールについて、インフレや株価下落が重なった場合のリスクを検証しています。

当初はPythonで計算ロジックを試作していましたが、コードだけでは他人に説明しづらく、条件変更もしにくいという課題がありました。

そこで、研究内容を視覚的に説明できるよう、HTML / CSS / JavaScriptのみで動作するオフラインWebアプリとして作成しました。

## 工夫した点

- 実装前に要件定義、画面設計、計算ロジック設計、テスト仕様書を作成した
- サーバー、DB、外部APIを使わず、index.html単体で動く構成にした
- 未経験者でも処理を追いやすいよう、JavaScriptの関数を役割ごとに分けた
- 不正な入力値に対してエラーメッセージを表示するようにした
- 破綻後は計算を止め、破綻年を明示するようにした
- 年次テーブルと簡易グラフで結果を確認できるようにした

## 苦労した点

- インフレ調整、生活費取り崩し、運用リターン反映の順序を決めること
- 乱数を使うため、テスト時に結果が毎回変わること
- 計算ロジックと画面表示を分けて整理すること
